# Portfolio — Digital Twin

A professional, mesmerizing single-page portfolio built with pure HTML, CSS, and JavaScript. No build step required.

## Features

- Dark theme with animated gradient orbs and film grain texture
- Smooth scroll reveal animations
- 3D tilt effect on project cards
- Animated stat counters
- Responsive mobile navigation
- Contact form (ready to connect to a backend)
- Fully accessible with reduced-motion support

## Quick Start

1. Open `index.html` in your browser, or
2. Use a local server: `npx serve .` (requires Node.js)

## Customize

Edit `index.html` to update:

| Section | What to change |
|---------|----------------|
| Hero | Your name, tagline, stats |
| About | Bio, photo (replace placeholder div with `<img>`) |
| Skills | Your tech stack |
| Projects | Project titles, descriptions, links |
| Experience | Job history |
| Contact | Email, LinkedIn, GitHub URLs |

## Deploy

- **GitHub Pages** — push to a repo and enable Pages
- **Netlify** — drag & drop the folder
- **Vercel** — import the repo

## Connect Contact Form

Replace the form submit handler in `js/main.js` with a service like [Formspree](https://formspree.io) or [EmailJS](https://www.emailjs.com).
