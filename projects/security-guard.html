The problem

Traditional CCTV surveillance relies heavily on continuous human monitoring, which leads to fatigue, delayed anomaly response, and missed security incidents. I built this AI system to continuously monitor camera feeds, track multi-person trajectories, and trigger immediate alerts upon detecting suspicious behavior or restricted area access.

Approach

Using custom-tuned YOLOv8 deep learning models paired with DeepSort object tracking algorithms, the system maintains consistent bounding-box IDs across video frames. Anomaly scoring algorithms evaluate movement trajectories in real-time, streaming processed video frames directly to a web dashboard via Flask.

Architecture

  • YOLOv8 object detection engine optimized for fast frame rate GPU inference
  • DeepSort tracking pipeline maintaining unique object IDs across camera occlusion
  • Flask REST server providing MJPEG live stream endpoints and threat alert logs
  • Custom rules engine evaluating perimeter breaches and erratic movement metrics
  • Database logging for incident timestamp review and analytics

Challenges

  • Occlusion and lighting shifts: ensuring tracking IDs persist when people walk past obstacles.
  • FPS optimization: maintaining 30+ frames per second under multi-stream video workloads.
  • Minimizing false positives: fine-tuning confidence thresholds for reliable threat scoring.

Results

  • 91% verified human detection accuracy across complex indoor and outdoor test feeds.
  • Real-time alert dispatching within 45ms of perimeter threshold violation.
  • Intuitive web monitoring HUD built with Flask and HTML5 canvas overlays.
