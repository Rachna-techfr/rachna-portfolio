Career Buddy

Multi-agent career platform with LangGraph & RAG, as a REST API

A cooperative multi-agent AI system that automates resume evaluation, skill gap analysis, interview simulation, and job recommendation using stateful LangGraph agents, FAISS vector search, and Streamlit + FastAPI deployment.

The problem

Job seekers and graduates struggle with fragmented career preparation tools: static resume builders lack intelligent feedback, generic interview prep questions fail to simulate real technical dialogue, and candidate skill gaps remain unidentified until rejection. I wanted to build an automated, end-to-end career copilot that directly understands candidate resumes, market requirements, and live interview conversations.

Approach

I designed a FastAPI REST backend powered by a stateful 5-agent LangGraph network. The system ingests resumes in PDF/text format, parses experience vectors into a FAISS retriever, orchestrates specialized agents for skill gap analysis and interview coaching, and reconciles output into structured JSON for Streamlit web consumption.

Architecture

  • FastAPI REST API with endpoints for resume intake, multi-agent evaluation, and voice audio streams
  • Stateful LangGraph multi-agent graph coordinating Resume Analyzer, Skill Matcher, Interview Coach, and Job Finder
  • FAISS vector database for semantic retriever augmentation over industry job descriptions and interview rubrics
  • Streamlit web dashboard with interactive graph visualization and live audio response feedback
  • Comprehensive evaluation logging and latency monitoring for production deployment readiness

Challenges

  • Complex multi-agent handoffs: maintaining conversation state across 5 distinct LangGraph nodes without losing context.
  • Unstructured resume parsing: extracting accurate skills, timelines, and metrics from heterogeneous PDF layouts.
  • Low-latency response: streaming model outputs efficiently to provide real-time audio interview feedback.

Results

  • Fully functional multi-agent career copilot serving resume scores, skill gaps, and interview prep.
  • High-precision RAG retriever providing grounded advice backed by real market job specs.
  • Modular, containerizable Python codebase ready for cloud microservices deployment.
