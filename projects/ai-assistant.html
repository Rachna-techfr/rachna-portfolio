The problem

Commercial cloud voice assistants (Siri, Alexa, Google Assistant) continuously record audio and stream private personal data to external servers, requiring constant internet connection and paid API tokens. I built a private, offline AI assistant that runs entirely on local hardware.

Approach

I integrated Ollama running quantized Mistral-7B with a local Flask backend. The assistant listens for voice commands via SpeechRecognition, parses intent using local NLP pipelines, triggers OS-level system scripts (opening apps, organizing files, fetching system health), and speaks back responses using pyttsx3.

Architecture

  • Ollama local LLM engine executing quantized 7B model inference
  • Speech-to-Text audio capture pipeline listening for wake words
  • Flask local server handling intent routing and system commands
  • System automation module interacting with OS processes and file structures
  • Offline text-to-speech audio feedback generator

Challenges

  • Local VRAM management: optimizing quantization so model fits within GPU memory.
  • Noisy voice capture: filtering background mic noise for accurate speech recognition.
  • Deterministic tool execution: ensuring LLM output calls system functions reliably without hallucination.

Results

  • 88% intent classification accuracy across daily system automation tasks.
  • 100% offline operation — completely private, secure, and subscription-free.
  • Fast local response times providing seamless desktop interaction.
