Hand Gesture Recognition

Touchless desktop automation via MediaPipe & KNN classifier

A real-time computer vision system that tracks 21 hand landmarks using MediaPipe Hands, classifies custom gestures via Scikit-Learn KNN models, and automates OS desktop controls seamlessly.

The problem

Physical peripheral devices like mice and keyboards can be inconvenient or unhygienic in sanitary medical environments, public kiosks, or immersive presentation setups. I wanted to design a fluid, highly responsive touchless interface that turns hand gestures directly into system actions.

Approach

I leveraged MediaPipe Hands to extract 21 3D hand landmark coordinates at high frame rates. Normalized landmark vectors are fed into a K-Nearest Neighbors (KNN) classifier trained on custom gesture samples, translating gestures into desktop commands with smooth cursor smoothing algorithms.

Architecture

  • OpenCV camera capture loop processing video frames at 60 FPS
  • MediaPipe Hands landmark extractor capturing 21 (x, y, z) spatial joint points
  • Scikit-Learn KNN model classifying open palm, fist, pinch, victory, and point gestures
  • Exponential smoothing filter eliminating jitter from cursor movement
  • PyAutoGUI desktop automation layer executing mouse clicks, drag, and volume changes

Challenges

  • Jitter reduction: smoothing raw coordinate noise without introducing input lag.
  • Distance invariance: ensuring gestures classify accurately regardless of hand distance from camera.
  • Multi-hand disambiguation: tracking primary user hand under crowded background conditions.

Results

  • 94% classification accuracy across 5 distinct hand gesture categories.
  • Sub-20ms processing latency providing instantaneous desktop response.
  • Seamless touchless navigation for media playback and screen control.
